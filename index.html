Van schoolopdrachten naar quant dev

Ik studeer Technical Computer Science aan de Universiteit Twente en werk toe naar een carrière als quantitative developer — de plek waar low-latency systems engineering en financiële modellen samenkomen. Momenteel bouw ik C++ trading-infrastructuur voor een cryptocurrency market-making systeem: real-time orderboekverwerking, een PostgreSQL/TimescaleDB tijdreeksdatabase en benchmarks voor kritieke-pad latency en throughput.

Naast mijn studie ben ik Investment Analyst, Financial Software Developer en External Affairs Board Member bij investeringsvereniging SBV Duitenberg, en lid van de Ledenraad van Rabobank. Deze site houdt bij wat ik onderweg bouw: schoolprojecten, eigen experimenten en de tools die ik daarbij leer beheersen.

Hyperliquid — C++ Market Making Infra

actief

Latency-gevoelige C++ tradinginfrastructuur voor een crypto market-making systeem: orderboekbeheer, marketdata-verwerking en quoting/executielogica op basis van real-time websocket-data. C++ Limit Order Book & Simulator

actief

Een C++ limit order book met order matching, bid/ask-beheer en trade-executielogica, gebouwd om marktmicrostructuur en orderboekmechanica in een gecontroleerde omgeving te modelleren. Matching werkt op basis van price-time priority.

C++ Order Matching Data Structures
